## 🚀 Sobre o projeto

O **Gerador de IA CSS** é uma aplicação web desenvolvida para transformar uma descrição escrita pelo usuário em uma estrutura de **HTML e CSS** utilizando Inteligência Artificial.

A proposta do projeto é permitir que o usuário descreva uma interface que deseja criar e receba uma sugestão de código para visualizar o resultado diretamente na aplicação.

Este projeto foi desenvolvido como parte da minha jornada de aprendizado em **Análise e Desenvolvimento de Sistemas**, com o objetivo de colocar em prática conhecimentos de desenvolvimento web, JavaScript e integração com APIs.

---

## ✨ Funcionalidades

- 🤖 Geração de código HTML e CSS utilizando IA
- 📝 Campo para descrever a interface desejada
- ⚡ Geração de código a partir da descrição fornecida
- 💻 Exibição do código gerado
- 🖥️ Pré-visualização do resultado
- 🎨 Interface simples e objetiva
- 📱 Estrutura preparada para diferentes tamanhos de tela
